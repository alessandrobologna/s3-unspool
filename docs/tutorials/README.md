# Tutorials

Tutorials teach the `s3-unspool` workflow through a small, reliable sequence.
They are for learning, not for exhaustive option lookup.

- [First Extract](first-extract.md): create a small local directory, zip it,
  extract it, and inspect the result.

For task-oriented recipes, use the [how-to guides](../how-to/README.md). For
option details, use the [reference](../reference/README.md).
